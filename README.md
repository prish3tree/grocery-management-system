# Grocery Management System

A web-based Grocery Management System built to manage products, inventory, customers, and orders efficiently.

## Project Overview

This project provides a simple interface for managing day-to-day grocery store operations. It uses a Python backend, MySQL database, and a web-based frontend.

## Technologies Used

- Python
- MySQL
- HTML
- CSS
- JavaScript

## Planned Features

- Product management
- Inventory management
- Customer management
- Order management
- Billing and order calculation
- MySQL database integration
